### High-Level Product Idea
- Learning reinforcement tool
- Sits on top of browser (cooler) OR web app that utilizes YouTube player API (easier)

- Listens to system audio
- Utilizes LLM to detect topics and ask quiz questions with stored results
- Customizes question styles based on cumulative user knowledge base


## MVP Scope (3-4 weeks)
Dependent on what we want to learn

*Definite:*
- Electron.js frontend with native Chromium using Mac ScreenCaptureKit (hopefully works)
- Stored knowledge base (DB)
- Proprietary agent framework
- Cloud deployment (AWS)

*Unsure:*
- Learning on knowledge base (can do a very simplified version with LLM prompt but that may suck)
